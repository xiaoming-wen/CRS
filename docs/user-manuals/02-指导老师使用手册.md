# 指导老师使用手册

适用角色：**指导老师（advisor）** / **教师（teacher）**  
二者在竞赛侧权限一致，下文统称「指导老师」。

---

## 1. 注册与登录

### 1.1 注册

1. 打开竞赛详情分享页或列表页，点击 **注册**。
2. 角色选择 **指导老师**。
3. 填写用户名、手机号、验证码、姓名、省份、**学校**、**指导老师编号**、密码。
4. 注册成功后可立即登录（无需额外核验）。

### 1.2 登录

打开：`https://www.chaoxiangedu.com/#/manu/competition-list`  
使用用户名与密码登录。

登录后侧栏主要使用 **竞赛列表与报名**；进入某场竞赛详情后使用 **组班与队务**。

---

## 2. 您能做什么 / 不能做什么

| 可以 | 不可以 |
|------|--------|
| 代学生创建队伍、指定队长与队员 | 以老师身份「报名参赛」 |
| 邀请队员、移除队员、修改队名 | 代替学生上传作品 / 答案 |
| 查看本人创建的队伍与花名册（只读相关） | 对学生作品评分 |
| 下载已发布的本赛试卷（在关联队伍场景下） | 跨本科 / 高职组别混组建队 |

---

## 3. 进入竞赛并组班

1. 在竞赛列表点击 **查看详情**。
2. 双组别竞赛请选择与学生一致的 **本科组** 或 **高职组**。
3. 详情页找到 **组班与队务（指导老师）**。

请先阅读页面上的「组队校审说明」：代建队成功后一般为 **待校审**，须本校校管理员审核通过后，队员方可上传题目答案 / 作品。

---

## 4. 创建队伍

在「创建队伍」表单中填写：

| 字段 | 说明 |
|------|------|
| 队名 | 选填 |
| 指导老师 | 自动为当前登录老师，不可改 |
| 赛道 | 必选：作品 / 软件 / 硬件 |
| 组别 | 必选：本科 / 高职（须与当前详情页一致） |
| 队长 | 选填与「初始队员」二选一至少填一类；可填**姓名**或 **8 位用户 ID** |
| 初始队员 | **选填**；多人用逗号分隔，每人可为姓名或 8 位用户 ID |

说明：

1. **初始队员可不填**，但须指定 **队长**（系统会以该学生建队）。
2. 若只填初始队员、不填队长，则默认列表中第一人为队长。
3. 若两者都填，队长 **必须出现在**初始队员列表中。
4. **不能把指导老师自己**写成队员。
5. 队员必须是 **学生** 账号，且尚未在本赛 **组队赛道** 有效报名。
6. 同名多人时请改用 **8 位用户 ID**。

点击 **创建队伍并拉入队员**。成功后：

- 队伍状态：**待校审**
- 可在下方「队伍列表与队务」中管理该队

---

## 5. 管理已建队伍

1. 点击 **刷新队伍列表**，选中队伍点 **管理**。
2. 可进行：
   - **修改队名**
   - **邀请入队**（填学生姓名或 8 位用户 ID）
   - **移除队员**（一般不能移除队长；决赛等阶段可能有额外限制）

仅 **由您创建** 的队伍可完整管理；其他人创建的队伍通常只能查看或不可操作。

---

## 6. 与校审、学生提交的关系

```text
指导老师代建队
    → 待校审
    → 本校校管理员「通过」
    → 已通过
    → 学生（通常队长）上传作品 / 决赛答案
```

若校审 **驳回**：相关组队报名退赛，需重新建队。

---

## 7. 试卷下载

管理员发布该组别试卷后，在已关联队伍的竞赛详情页，可使用工具栏 **下载试卷**（以页面是否显示为准）。

---

## 8. 常见问题

**Q：提示无法在本组别组班？**  
A：您可能已在另一学历组别建过队。请打开对应组别的详情页管理，或联系管理员。

**Q：创建失败：找不到学生 / 已报名？**  
A：核对 8 位用户 ID；确认对方是学生账号；确认对方未在本赛组队赛道已报名。

**Q：学生说交不了作品？**  
A：先看队伍是否仍为「待校审」。请本校校管理员在「校审」中通过该队。

**Q：我能帮学生点报名吗？**  
A：不能。请使用「创建队伍」把学生拉进队；报名随建队 / 入队完成。

---

## 9. 操作检查清单

- [ ] 学校名称与学生所属学校一致  
- [ ] 从正确组别进入详情再组班  
- [ ] 已指定队长（或初始队员）且 ID 正确  
- [ ] 建队后提醒校管及时审核  
- [ ] 提醒队长在「已通过」后按时交作品
