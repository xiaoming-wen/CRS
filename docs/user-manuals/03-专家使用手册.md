# 专家使用手册

适用角色：**专家（expert）** — 负责对已指派竞赛的作品 / 答案进行评阅打分。

---

## 1. 注册、核验与登录

专家账号有两道门槛：**管理员核验** 与 **竞赛指派**。

### 1.1 注册

1. 打开独立注册页：  
   `https://www.chaoxiangedu.com/#/manu/competition-register`
2. 角色选择 **专家**。
3. 填写用户名、手机号、验证码、姓名、省份、学校、密码并提交。
4. 注册成功后请 **记下您的 8 位用户 ID**，交给竞赛管理员。

此时账号为 **未核验**（`expert_verified=false`）。

### 1.2 等待管理员核验与指派

请竞赛 **超级管理员** 完成：

1. **核验专家身份**：将您的账号设为已核验。  
2. **指派竞赛（及队伍）**：把您指派到具体竞赛；通常还需指定可评的队伍。

未核验时尝试登录会失败（提示待管理员审批）。

### 1.3 登录

核验通过后，打开：  
`https://www.chaoxiangedu.com/#/manu/competition-list`  
使用用户名与密码登录。

---

## 2. 评阅范围

| 可以 | 不可以 |
|------|--------|
| 查看 **已指派** 竞赛的分题答案并按题下载 | 评阅未指派给您的竞赛 |
| 下载附件、进行评分 / 改分 | 报名、组队、替学生交作品 |
|  | 管理竞赛发布、校审队伍 |
|  | 查看评分汇总 / 排行榜 |

若打开某竞赛详情提示「未指派到本竞赛」，请联系管理员重新指派。

---

## 3. 评阅操作步骤

1. 登录后进入 **竞赛列表**，打开已指派的竞赛 **详情**。
2. 在 **题目答案列表** 中按队伍查看第1～第5题是否已提交：
   - 按需 **下载** 各题附件到本地审阅
   - 每题下方显示该题分数，最右侧显示 **总分**
3. 点击 **评分 / 修改评分**，为 5 道题分别打分（每题 0～100），系统自动合计总分后保存。

建议：

- 评分前确认赛道（作品 / 软件 / 硬件）与组别（本科 / 高职）是否为您的评阅范围。  
- 修改分数后再次确认保存成功提示。

---

## 4. 账号与权限状态说明

| 状态 | 含义 |
|------|------|
| 已注册、未核验 | 不能登录 |
| 已核验、未指派竞赛 | 可登录，但打开竞赛时无法评阅 |
| 已核验且已指派 | 可在指派竞赛中评分 |

改角色或重新核验后，如权限异常，请 **退出后重新登录** 刷新令牌。

---

## 5. 常见问题

**Q：注册后无法登录？**  
A：专家须管理员核验后才能登录。请向超级管理员提供用户名与用户 ID。

**Q：能登录但看不到作品或不能打分？**  
A：多半尚未指派到该竞赛，或指派时未勾选对应队伍。请管理员检查指派。

**Q：可以自己报名参赛吗？**  
A：专家角色不能报名或组队。如需参赛请使用单独的学生账号。

**Q：超级管理员能代替我评分吗？**  
A：评分接口面向已核验且已指派的专家；请由专家账号本人完成评阅。
