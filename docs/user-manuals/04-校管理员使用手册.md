# 校管理员使用手册

适用角色：**校管理员（school_admin）**  
主要职责：审核本校学生 / 指导老师创建的组队申请；必要时代建已通过的队伍。

---

## 1. 注册、申请与登录

校管理员可注册后登录，但须完成 **资料申请并经超级管理员通过** 后，才能做组队校审。

### 1.1 注册

1. 打开：  
   `https://www.chaoxiangedu.com/#/manu/competition-register`
2. 角色选择 **校管理员**。
3. 填写用户名、手机号、验证码、姓名、省份、**学校**（务必与本校正式名称一致）、密码。
4. 注册成功后即可登录。

### 1.2 登录后先「申请校管」

1. 打开列表壳页面并登录。  
2. 侧栏进入 **申请校管**（未通过前通常看不到完整竞赛业务菜单）。  
3. 提交资料：
   - **照片为必填**（单张，常见限制约 5MB 以内）
   - 联系方式、备注为选填  
4. 提交后状态为 **审核中（pending）**，等待超级管理员审批。

| 申请状态 | 含义 |
|----------|------|
| 未提交 | 尚未交资料 |
| 审核中 | 等待超管审批 |
| 已通过 | `school_admin_verified=true`，可使用「校审」 |
| 已驳回 | 可按反馈修改后重新提交 |

### 1.3 通过后使用「校审」

侧栏出现 **校审** 后，即可审核本校相关组队。

---

## 2. 组队校审

### 2.1 审核列表

在「校审」中可按状态筛选：

- **待校审**：学生或指导老师新建队伍，等待您处理  
- **已通过**：可组队交作品  
- **已驳回**：相关组队报名已退赛  

### 2.2 通过 / 驳回

1. 核对队伍所属学校、队长与队员是否为本校人员。  
2. 核对组别（本科 / 高职）、赛道等信息是否合理。  
3. 操作：
   - **通过** → 队伍变为「已通过」，队员可上传作品 / 答案  
   - **驳回** → 队伍「已驳回」，相关组队报名自动退赛  

请谨慎驳回，并建议通过线下渠道告知队长原因。

### 2.3 与超管的关系

校管与超级管理员共享同一套队伍审核状态。任一方通过或驳回后，状态一致生效。

---

## 3. 代建队报名（可选）

部分页面提供校管 **代建队** 功能，用于协助本校快速组队：

1. 选择竞赛、组别、赛道。  
2. 填写队长 / 队员用户名（及可选指导老师用户名）。  
3. 提交后，队伍通常直接为 **已通过（active）**（与学生 / 老师自建进入「待校审」不同）。

具体字段以「校审」页表单为准。

---

## 4. 您不能做什么

- 不能代替专家评分  
- 日常不作为选手报名、交作品（请使用学生账号）  
- 未通过资料申请前，不能查看 / 操作组队校审列表  

---

## 5. 推荐工作流程

```text
学生或指导老师建队（待校审）
        ↓
校管理员在「校审」中核对并「通过」
        ↓
队伍已通过 → 学生按时提交作品 / 决赛答案
```

建议在报名高峰期每日查看「待校审」列表，避免学生因未通过校审无法交件。

---

## 6. 常见问题

**Q：登录后没有「校审」菜单？**  
A：请先完成「申请校管」并等待超级管理员通过。

**Q：为什么有的队伍不在列表里？**  
A：校审一般针对 **本校** 相关组队。请确认建队学生 / 老师的学校字段与您的学校一致。

**Q：驳回后学生怎么办？**  
A：相关组队报名已退赛，需重新建队并再次进入待校审。

**Q：学校名称填错了怎么办？**  
A：学校字段影响审核归属。请联系超级管理员协助更正账号资料。

---

## 7. 操作检查清单

- [ ] 注册时学校名称填写正确  
- [ ] 已提交校管资料（含照片）并获「已通过」  
- [ ] 定期处理「待校审」队伍  
- [ ] 通过前核对组别 / 队员为本校人员  
- [ ] 重大驳回后通知相关师生
