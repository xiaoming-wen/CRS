# 学生使用手册

适用角色：**学生（student）**

---

## 1. 注册与登录

### 1.1 注册

1. 打开竞赛分享链接或列表页，点击 **注册**。  
   - 推荐从竞赛详情页注册：`#/manu/competition-detail?id=竞赛ID&share=1`
2. 填写：
   - 用户名、手机号、短信验证码
   - 姓名、省份、**学校**（须与本校正式名称一致，便于校审匹配）
   - 角色选择 **学生**
   - **学号**
   - 密码（不少于 6 位）
3. 提交成功后即可用该用户名登录。

> 独立注册页 `#/manu/competition-register` 主要用于专家 / 校管理员，**学生请走详情页或列表页的注册入口**。

### 1.2 登录

1. 打开：`https://www.chaoxiangedu.com/#/manu/competition-list`
2. 输入用户名与密码，点击登录。
3. 登录后可在侧栏进入：
   - **竞赛列表与报名**
   - **我报名的竞赛**（也可直接打开 `#/manu/my-enrollments`）

登录后请留意页面或个人资料中展示的 **8 位用户 ID**，加入队伍或被老师邀请时需要。

---

## 2. 查看竞赛与进入组别

1. 在「竞赛列表」中找到目标竞赛，点击 **查看详情**。
2. 若竞赛分 **本科组 / 高职组**，请先选择自己所属组别再进入详情。
3. 分享链接示例：
   - 本科组：`.../competition-detail?id=竞赛ID&division=undergraduate&share=1`
   - 高职组：`.../competition-detail?id=竞赛ID&division=vocational&share=1`

**重要：** 同一竞赛只能在一个学历组别报名，不可本科、高职两边都报。

---

## 3. 组队报名（常用流程）

当前参赛流程以 **组队** 为主。

### 3.1 填写报名资料

在详情页填写学号、姓名、学院、联系方式等资料（按页面要求），保存后再建队或申请入队。

### 3.2 方式 A：自己创建队伍（成为队长）

1. 在详情页选择 **创建队伍**。
2. 填写队名、赛道（作品 / 软件 / 硬件）、组别（本科 / 高职）。
3. 指导老师为 **选填**，可填**姓名**或 **8 位用户 ID**（精确匹配系统账号时会绑定到该老师，方可在老师端看到队伍）。
4. 提交后：
   - 您成为 **队长**
   - 自动完成 **组队赛道报名**
   - 队伍状态为 **待校审**

### 3.3 方式 B：申请加入已有队伍

1. 在详情页选择 **加入队伍**，按提示填写队名或队伍 ID。
2. 提交后等待 **队长审核**。
3. 审核通过后：自动入队并完成组队赛道报名。

### 3.4 等待校审

| 状态 | 您可以做什么 |
|------|----------------|
| 待校审 | 可继续邀请/管理队员（队长）；**不能**上传作品或题目答案 |
| 已通过 | 可按竞赛阶段提交作品或答案 |
| 已驳回 | 组队报名失效，需重新建队或联系校管了解原因 |

---

## 4. 队长常用操作

在详情页「我的队伍」相关区域，队长可以：

1. **邀请队员**：输入对方 **8 位学生用户 ID**。
2. **审核入队申请**：通过或拒绝。
3. **转让队长**：将队长身份转给其他队员。
4. **退队 / 退赛**：按页面提示操作（注意：退赛后该赛道作品通常需重新报名后再交）。

队员一般 **不能** 再次建队报名；请跟随队长与本校安排。

---

## 5. 提交作品 / 题目答案

须满足：**队伍校审已通过**，且竞赛处于允许提交的阶段。

### 5.1 初赛 / 单阶段（常见）

- 通常由 **队长** 上传作品压缩包（如 `.zip`）。
- 同一报名周期内，已提交后可能无法再次提交；退赛重新报名后才可交新作品（以页面提示为准）。

### 5.2 决赛

- 仅 **初赛晋级** 队伍可在决赛阶段上传。
- 一般按题目分别上传答案；请按详情页题目槽位操作。

### 5.3 下载试卷

若管理员已发布本组别试卷，详情页工具栏可出现 **下载试卷**。请使用已报名且组别匹配的账号下载。

---

## 6. 查看成绩与我的报名

1. **我的成绩**：在详情页查看本人 / 本队相关成绩（若已开放）。
2. **我报名的竞赛**：侧栏或 `#/manu/my-enrollments`，可查看赛道、组别，并按需退赛。

## 7. 常见问题

**Q：提示无法在本组别报名？**  
A：您可能已在另一学历组别报名。请返回列表，从已报名的组别进入详情。

**Q：为什么不能上传作品？**  
A：检查队伍是否仍为「待校审」，或是否已被驳回；决赛阶段还需确认是否已晋级。

**Q：指导老师能为我报名吗？**  
A：指导老师不能替学生点「报名」，但可以 **代建队伍并拉入学生**；校审通过后由学生侧提交作品（通常队长操作）。

**Q：忘记用户 ID？**  
A：登录后在个人资料 / 账号信息中查看 8 位 ID；或联系指导老师、校管理员查询。
