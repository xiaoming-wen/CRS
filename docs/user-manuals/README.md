## 通用说明

1. **账号体系**：请使用「竞赛独立账号」登录（用户名 + 密码），与主站其它系统账号不通用。
2. **用户 ID**：每位用户有一个 **8 位数字**用户 ID，建队、邀请队员时常用到。
3. **竞赛 ID**：每场竞赛也是 **8 位数字** ID，详情链接形如  
   `#/manu/competition-detail?id=竞赛ID`
4. **双组别竞赛**：若竞赛分本科组 / 高职组，须从对应组别进入详情，**不可跨组报名或混组**。
5. **队伍校审状态**：

| 状态 | 含义 |
|------|------|
| 待校审 | 建队成功，等待本校校管理员审核 |
| 已通过 | 可组队提交作品 / 上传题目答案 |
| 已驳回 | 组队报名作废，需重新建队 |
